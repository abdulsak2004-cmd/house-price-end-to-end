# House Price Prediction — End-to-End ML Project

An end-to-end machine learning project to predict residential house prices using the Kaggle House Prices dataset, covering SQL exploration, statistical analysis, machine learning, deployment, and testing.

## Dataset

[Kaggle — House Prices: Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data)

## Tech Stack

- Python
- SQL
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- JupyterLab
- PyCharm
- Git & GitHub
